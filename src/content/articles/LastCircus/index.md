ラストサーカス～最後の公演に隠された真実を追え～\
\
**企画概要**\
\
「ラストサーカス」は、高校1年生による有志企画として、当日は33Rで開催する謎解き・探索型の体験企画です。\
\
本企画では、かつて存在した一つのサーカス団を舞台に、最後の公演で起きた出来事と、その後に起こった不可解な事件を追っていきます。\
\
参加者は、会場に用意されたストーリーを読み進めながら、そこに登場する出来事や人物について、実際に展示されている資料を調べていきます。

これらの資料は、単なる展示物ではありません。それぞれがストーリーの一部となっており、資料を詳しく見ることで、文章だけでは分からなかった情報や、新たな事実を発見することができます。\
\
**ストーリー**\
\
かつて、多くの観客を集めていたサーカス団がありました。\
\
華やかな衣装を身にまとった団員たちが舞台に立ち、観客を楽しませるショーを繰り広げていた、どこにでもあるようなサーカス団でした。\
\
しかし、ある日の公演を境に、そのサーカス団は突然姿を消します。\
\
公演を見ていた観客や当時の関係者からは、いくつかの証言が残されています。しかし、時間が経つにつれて事件について語られることは少なくなり、いつしかその出来事は忘れられていきました。\
\
現在残されているのは、当時の新聞記事や写真、チケット、そして行方不明となった団員を探すために作られたポスターなど、わずかな資料だけです。\
\
なぜサーカス団は消えたのか参加者は残された資料を手がかりに、その真相を追っていきます。\
\
**「知るほど怖くなる」ストーリー**\
\
この企画の大きな特徴は、最初から事件の全容が明らかになっているわけではないということです。\
\
物語の序盤では、参加者はサーカス団についての基本的な情報しか知ることができません。\
\
しかし、ストーリーを読み進め、資料を一つずつ確認していくことで、少しずつ過去の出来事がつながっていきます。\
\
最初は何気なく見ていた一枚の写真や新聞記事が、後から重要な意味を持っていることに気づくこともあります。\
\
**「この人物は誰なのか」**\
\
「なぜこの新聞記事が残されているのか」\
\
「この写真が撮影されたのはいつなのか」\
\
「行方不明になった団員たちは、その後どうなったのか」\
\
さまざまな疑問を抱えながら資料を読み進めることで、参加者は少しずつ事件の核心へと近づいていきます。\
\
そして、バラバラだった情報が一つにつながったとき、これまで見ていた資料の意味が大きく変わります。\
\
知れば知るほど真実に近づく。\
しかし、真実に近づくほど、知りたくなかったことまで見えてくる。\
\
そんな「真相が分かっていくこと自体が怖い」という感覚を、この企画では大切にしています。\
\
**最後に**\
\
あなたが最初に見るのは、ただの古い資料かもしれません。\
\
しかし、そこに書かれている一つひとつの情報をつなぎ合わせていくと、忘れ去られていたサーカスの過去が少しずつ姿を現します。\
\
最後の公演で何が起きたのか。\
消えた団員たちはどこへ行ったのか。\
そして、あなたが最後にたどり着く真実とは何なのか。\
\
**すべての資料を見終えたとき、あなたは「ラストサーカス」の本当の意味を知ることになります。**
